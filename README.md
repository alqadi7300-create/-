# برنامج محمد القاضي التعليمي العلمي

تطبيق Flutter باللغة العربية لدعم طلاب الصفوف الأول والثاني والثالث الثانوي في مواد الكيمياء والفيزياء والأحياء.

## الموجود في النسخة الأولية
- واجهة عربية باتجاه RTL.
- اختيار الصف والمادة.
- إضافة الدروس وعرضها وحذفها من وضع المعلم.
- حفظ الدروس النصية محليًا داخل التطبيق للاستخدام دون اتصال.
- سير عمل GitHub Actions لبناء APK ورفعه كـ Artifact.

## تشغيل محلي
1. ثبّت Flutter SDK.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

## بناء APK
ادفع تغييرات إلى فرع `main)، أو شغّل يدويًا سير العمل من تبويب Actions. بعد نجاحه، نزّل الملف من Artifact باسم `mohamed-alqadi-education-apk`.

## ملاحظة مهمة
رمز المعلم الحالي (1234) تجريبي فقط وغير آمن للإنتاج. الدروس تحفظ محليًا على جهاز واحد؛ لم تتم إضافة قاعدة بيانات مشتركة أو حسابات طلاب/معلمين حقيقية بعد. أقسام الكتب والاختبارات والنتائج ولوحة الشرف مخطط لها للمرحلة التالية.
